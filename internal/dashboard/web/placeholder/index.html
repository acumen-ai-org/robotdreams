Mission Control was not built into this binary

This dream binary was compiled without the dashboard's Vite build output. The API it serves is unaffected; only this UI is missing.

To build a binary that includes Mission Control, run from the repository root:

make build

which builds the UI (internal/dashboard/ui, Node 22+) into internal/dashboard/web/ and then compiles the Go binary with it embedded. See docs/dashboard.md.
